# 心理學背景如何開始 Open Neuroscience？

這份指南提供給具有心理學背景、但剛開始接觸 Open Science、Open Neuroscience、Git/GitHub 與 BIDS 的初學者。

## 1. 從研究問題開始，而不是從程式開始

心理學背景的學習者可以先從熟悉的研究問題開始，例如：

- 語言學習
- 記憶
- 注意力
- 情緒
- 恐懼
- 焦慮
- 臨床心理相關議題

接著再思考：

- 是否已有相關神經影像研究？
- 是否有公開資料可以重新分析？
- 是否有公開工具可協助探索？
- 是否需要使用 BIDS 整理資料？

## 2. 初學者可以先認識的資源

### NeuroQuery
適合用來探索某個心理學概念與哪些腦區或神經影像文獻相關。

### Neurosynth
適合探索既有 fMRI 文獻與 meta-analysis 結果。

### Neurosynth Compose
適合建立與管理 neuroimaging meta-analysis 專案。

### OpenNeuro
適合尋找公開的 MRI、fMRI、EEG、MEG 等資料集。

### OpenNeuroscience Resources
適合瀏覽更多 Open Neuroscience 工具、資料庫與開源資源。

## 3. BIDS 是什麼？

BIDS（Brain Imaging Data Structure）是一套神經科學資料的標準化組織與命名規則。

它不是分析軟體，而是協助研究者以一致方式整理與共享資料。

## 4. Git 和 GitHub 是什麼？

Git 是版本控制工具。

GitHub 是用來託管 Git repository 並進行協作的平台。

初學者可以先熟悉：

- `git clone`
- `git status`
- `git pull`
- `git add`
- `git commit`
- `git push`

## 5. 建議學習路徑

心理學研究問題  
→ 探索相關文獻  
→ 尋找公開資料  
→ 理解 BIDS  
→ 使用 Git/GitHub 協作  
→ 再逐步學習分析工具
